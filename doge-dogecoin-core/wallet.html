Link a Trezor Dogecoin account (public key only)

  1. Open Trezor Suite → your Dogecoin account → the ⋯ menu → Show public key (XPUB).
  2. Paste the key below. It starts with dgub or xpub. Never paste anything starting with dgpv/xprv — that is a private key and this page refuses it.
  3. Optionally enter the date the account was created so the node rescans its history. Without a date only future transactions are tracked.

How this stays safe

  1. The node only holds watch-only addresses. There is no code path that can derive, import or store a private key.
  2. Spends are built from your node's own coin data and signed only on the Trezor, which displays amount and recipient on its screen.
  3. Trezor Connect is loaded from connect.trezor.io only when you click Connect Trezor; the page's Content-Security-Policy blocks every other origin.
  4. Broadcast goes through your node, not a third-party API. Receive addresses can be verified on the device.
  5. Reach this page only through your Umbrel (its login protects it). Never through a link someone sent you.
